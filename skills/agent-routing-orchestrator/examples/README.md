# Agent Routing Examples

Copy these prompts into your first message when invoking `agent-routing-orchestrator`. Adjust host, autonomy, and verification fields for your environment.

| Example | Use when |
|---|---|
| [minimal-prompt.md](minimal-prompt.md) | You want safe defaults with a short contract |
| [branch-review.md](branch-review.md) | Reviewing a branch before merge or release |
| [failing-test-handoff.md](failing-test-handoff.md) | Delegating a bounded test investigation |
| [architecture-challenge.md](architecture-challenge.md) | Pressure-testing a design before implementation |
| [ci-worker-routing.md](ci-worker-routing.md) | Routing work through CI or background workers |

See also [docs/USAGE.md](../../docs/USAGE.md) for longer walkthroughs.
